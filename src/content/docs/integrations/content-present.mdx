## Shiki 代码

你可以在配置文件 `astro.config.ts` 的 `defineConfig.markdown.shikiConfig` 中更改转换器。

### 基本用法

对于 `.astro` 文件：

```astro
---
import { Code } from 'astro:components'
---

<Code lang='shell' code={`git log --oneline`} />
```

对于 `.mdx` 和 `.md` 文件：

````markdown
```shell
git log --oneline
```
````

## 内容过时提醒

如果文章足够旧，添加一条提醒消息。

```astro title="src/layouts/BlogPost.astro"
---
// ...
---
  <Hero {data} {remarkPluginFrontmatter} slot='header'>
    <Fragment slot='description'>
      {!isDraft && enableComment && <PageInfo comment class='mt-1' />}
      { // [!code ++]
        Math.floor((Date.now() - new Date(articleDate).getTime()) / 86400000) > 365 && ( // [!code ++]
          <p class='mt-1 text-sm italic text-primary' style='--primary:41 90% 50%'> <!-- [!code ++] -->
            This article was last updated over a year ago. Some information may be outdated. <!-- [!code ++] -->
          </p> /* [!code ++] */
        ) // [!code ++]
      } <!-- [!code ++] -->
    </Fragment>
  </Hero>
```

渲染效果如下：

{
  <p class='mt-1 text-sm italic text-primary' style='--primary:41 90% 50%'>
    这篇文章上次更新已超过一年，部分信息可能已过时。
  </p>
}
