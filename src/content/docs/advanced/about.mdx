## 贡献代码

非常感谢所有为 [astro-theme-pure](https://github.com/cworld1/astro-theme-pure) 做出贡献的人。开源社区因你们而精彩。

[![贡献者](https://contrib.rocks/image?repo=cworld1/astro-theme-pure)](https://github.com/cworld1/astro-theme-pure/graphs/contributors)

<Aside title='贡献指南'>
修复 bug 或新增功能是你所能做出的最直接的贡献形式。最好先提交一个 issue 讨论你想要更改的内容，这样可以避免不必要的工作，尤其是当你想进行突破性更改时。

对 `astro-pure` 包的所有更改都应先启用 [自定义主题#包模式](/docs/advanced/customize#package-mode)。PR 测试也将在该模式下运行。这要求你先在本地使用 `bun run yijiansilian` 命令测试你的更改。

对于贡献文档，你只需点击每个文档页面底部的 "Edit on GitHub" 链接即可修改文档内容。
</Aside>
